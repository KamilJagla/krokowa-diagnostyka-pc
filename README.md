# krokowa-diagnostyka-pc
# Aplikacja do krokowej diagnostyki usterek komputerowych (WCAG)

Projekt dyplomowy realizowany na kierunku **Elektroniczne Przetwarzanie Informacji (EPI)** na Uniwersytecie Jagiellońskim w Krakowie.

## Cel projektu
Stworzenie dostępnej aplikacji internetowej wspierającej seniorów oraz osoby o niskich kompetencjach cyfrowych w samodzielnym rozwiązywaniu typowych problemów komputerowych. Interfejs projektowany jest zgodnie ze standardami **WCAG 2.1** oraz zasadami redukcji obciążenia poznawczego (prezentacja jednego prostego kroku na ekranie).

## Planowany stos technologiczny
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** Python (Flask / FastAPI)
* **Baza danych:** SQLite / PostgreSQL
